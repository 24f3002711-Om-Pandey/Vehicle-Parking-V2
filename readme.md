Introduction
This project is a web-based Vehicle Parking Management System built using Flask and SQLAlchemy. It allows users to reserve parking spots, track their reservations, and view historical usage. Admins can manage parking lots, monitor system activity, and oversee user access.

Technology Stack
Frontend: HTML, CSS (Bootstrap optional)
Backend: Python (Flask Framework)
Database: SQLite via SQLAlchemy ORM
Tools: python-dotenv, Jinja2, Werkzeug

Key Features
User Module:
Register, login/logout
Reserve multiple spots
View profile & reservation history
Monthly cost visualization

Admin Module:
Add/manage parking lots
Auto-create spots
Ban/unban users
Admin dashboard with search and analytics
